## 1. 仕様(原文)

- waveになっており、モンスターを一定数撃破するとクリア
- wave中はレベルアップができず貯蓄経験値として保存される。クリア時に貯蓄経験値が経験値として取得(経験値やアイテム等は個別で取得、同期しない)
- 3分撃破に間に合わない場合闇の霧
- 画面の派手さを防ぐために、メイン武器、サブ武器を1つのみ所持できる。超えた数は最終ダメージ +10%/個 に変換される
- 敵のHPはプレイヤー数で倍率がかかる。×1.0, ×1.5, ×2.0, ×2.5
- 1階層毎に敵レベル +1
- ボスフェーズ以外でのwaveクリア速度に応じて階層をスキップできる。最大 +3、ボスウェーブはスキップできない。スキップした際に経験値を貯蓄経験値×スキップ数を得る
- ステージはそのボスが出現する種類にする
- 5階層毎にボスが出現する
- 40層からカオス強化が適応されるようになる(最大レベル)
  - 通常: 膨れる殺意、狂騒、枯れた大地、蝕む呪い
  - ボス: 膨れる殺意、狂騒、枯れた大地、蝕む呪い、血の夜明け、双王
  - 周回毎に適応数が1つ増える
  - 血の夜明け、双王は両方は選ばれない
- また他のステージからの敵も合わさって出現するようになる(七彩の晶窟 + 陽炎の砂海など)

### ボスの階

| 階 | ボス |
|---|---|
| 5、10 | tier 1 |
| 15、20 | tier 2 |
| 25、30 | tier 3 |

| 40 | tier 4 の 2番目(時計塔・王墓・聖堂の 2体目) |
| 45〜 | 以下繰り返し(45・50 = tier 1 …) |

## 2. 今のコードでの読み方

| 仕様 | 作り方 |
|---|---|
| wave・撃破数でクリア | 1階 = 1 wave。その階の撃破数に届いたらクリアして次の階へ |
| 3分で闇の霧 | 階ごとに霧の時計を 0 から(通常の階はフェーズを作らない。#19)。180秒(`DATA.flow.fog.start`)で今と同じ闇の霧(1秒ごとに HP −1、10秒ごとに +1) |
| 貯蓄経験値 | wave 中に拾った経験値は貯めるだけ(レベルが上がらない)。クリアした時にまとめて入り、上がった分のレベルアップを選ぶ |
| 武器はメイン 1・サブ 1 | 武器枠を 2 にする。「超えた数」= 武器枠(基本 4 + ツリー + 百刃の)− 2。1つにつき最終ダメージ +10%(基本の 4枠なら +20%)。`dmgMul()` に別の倍率として掛ける(攻撃力・与えるダメージとは掛け算) |
| 敵の HP の倍率 | 1人 ×1.0 / 2人 ×1.5 / 3人 ×2.0 / 4人 ×2.5。ボスにも掛ける |
| 1階ごとに敵Lv +1 | 敵Lv = 階の番号(スキップした階も数える)。時間では上がらない |
| ステージ = ボスのステージ | 闘技場の顔ぶれ(`arenaOrder`)と同じ選び方。ランの始めに tier ごとにステージを 2つ選び、1〜5階は 1つ目のステージ(5階はそのステージのボス 2体のどちらか)、6〜10階は 2つ目 … 31〜35階は tier 4 の 1体目のどれかのステージ、36〜40階は tier 4 の 2体目のどれかのステージ |
| カオス強化(最大レベル) | 膨れる殺意 Lv5(攻撃範囲 +25%)・狂騒 Lv3(攻撃頻度 +30%)・枯れた大地 Lv5(アイテム −50%)・蝕む呪い Lv5(デバフ +50%)・血の夜明け・双王 |

## 3. 協力プレイで共有するもの・個別のもの

協力プレイは後で作るが、タワーを 1人用で作る時から、この分け方を崩さないようにする。

| 共有(全員で同じ) | 個別(1人ずつ) |
|---|---|
| 今の階・その階の撃破数 | 貯蓄経験値・経験値・レベル |
| 闇の霧の時計 | レベルアップのカード |
| ボス・敵(HP は人数の倍率) | 武器・最終ダメージの倍率 |
| その階のカオス強化の組 | 拾うもの(ジェム・アイテム・ゴールド・宝箱) |
| ステージ | HP・状態異常 |
