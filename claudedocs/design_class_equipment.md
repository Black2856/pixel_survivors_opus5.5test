## 2. 全体構造

```

[永続] クラスレベル    クラスごと Lv1〜20。ラン終了時にクラス経験値を得る (4章)

```

## 3. クラス

### 3.1 構成要素

| 要素 | 操作 | 内容 |
|---|---|---|
| クラス特性 | - | 専用のリソースやバフなど、他の要素と相互作用するシステム |
| パッシブ | - | 常時発動するバフ(クラス固有) |
| クラススキル | **Q** | 必殺技・打開スキル |
| 防御スキル | **Space** | クラス固有(ダッシュ / ガード / テレポートなど)。スタミナを消費する(3.3) |
| メイン武器 | 通常攻撃: 自動 / 武器スキル: **E** | クラスが最初から持つ武器。クラスLv15で変更できる(4章)。切り替えると E も変わる |

### 3.2 スキルの共通ルール

- E と Q は、設定で自動発動にもできる
- クールダウンの目安は **20〜60秒**。クールダウンのステータスが影響する。専用リソースを消費するスキルは対象外
- ダメージがあるスキルは、倍率をかなり高めにする
- **ダメージの基準**

| 出どころ | 基準 | 式 |
|---|---|---|
| クラス側(特性・パッシブ・Q・防御スキル) | 固定の**基礎威力**。武器に依存しない | `基礎威力 × (1 + 攻撃力%) × 強化倍率 × 会心` |
| 武器側(通常攻撃・E・進化) | その武器の**威力**(武器Lv 表) | `武器の威力 × 倍率 × (1 + 攻撃力%) × 会心` |
| 継続・派生(炎上・雷の連鎖など) | 元になった攻撃の**与ダメージ** | `与ダメージ × x%` |

  - メイン武器を切り替えても、クラスのスキルの強さは変わらない
- **E / Q の演出方針**: 必殺技として、**かなり派手で気持ちよく**感じる演出にする
  - 発動の瞬間: 短いヒットストップ(`hitstop`)かスロー(`slowmo`)を入れて「溜め」を作り、スキル名のカットイン(`UI.announce`)を出す
  - 命中・炸裂: 画面揺れ(`shake`)、画面フラッシュ(`screenFlash`)、衝撃波(`shockAt`)、リング(`addRing`)、大量のパーティクル(`burst`)を重ねる
  - 音: 専用の効果音を用意し、低音の衝撃音を重ねる
  - 通常攻撃との差: 通常攻撃は控えめのまま、E / Q だけを突出させてメリハリを付ける
  - 設定を守る: 自分の攻撃の強さの設定(`SET.fxA`)とグラフィック品質(`SET.gfx`)でスケールする。ポストエフェクトは品質が high / mid のときだけ使う
  - 見やすさ: 敵の攻撃(赤い輪郭)が演出に埋もれないようにする。フラッシュと揺れは短くする
- **E / Q の予備動作**: E と Q に限り、プレイヤーが動けない予備動作(構え・詠唱)や硬直を入れてよい
  - 目安: 予備動作は 0.2〜0.5秒。スキル後の硬直は 0.3秒以内
  - 予備動作中は**ノックバックを受けない**(スーパーアーマー)。ダメージは通常どおり受ける。無敵にするかどうかはスキルごとに決める
  - 予備動作の間に、演出の「溜め」(スロー・光・魔法陣)を重ねて、動けない時間を気持ちよさに変える
  - 自動発動の設定では、予備動作があるスキルは周囲に敵が一定数いるときだけ発動する(移動中に勝手に止まるのを防ぐ)
  - 防御スキル(Space)と通常攻撃には、予備動作を入れない
- **クラスと武器の独立ルール**
  - 武器側(通常攻撃・E・E の強化と特殊強化・進化)は、特定クラスの仕組み(剣気・共鳴・居合など)を**直接参照しない**。他のクラスが持ったときに死に効果になるため
  - クラス側から武器を参照するときは、「通常攻撃」「武器スキル」「命中」「攻撃回数」など、どの武器にもある言葉だけを使う
  - シナジーは**間接的**に作る。例: バラージュは攻撃回数が多いので、メイジが使うと元素循環が速く回り、共鳴が起きやすい
  - 基礎威力の目安: 武器Lv3 の威力(約20)を「攻撃力 ×100%」と見なして換算した

### 3.4 ラン中の強化

**強化カテゴリ**

| 系統 | カテゴリ | 強化パス数 | 各パス最大Lv | 出るタイミング |
|---|---|---|---|---|
| クラス | パッシブ | 3 | 3 | 3Lvごと |
| クラス | クラススキル (Q) | 3 | 3 | 3Lvごと |
| 武器 | 武器スキル (E) | 3 | 3 | 3Lvごと(クラス側と同じ候補に混ぜる) |
| クラス | クラス特性 | 3 | 3 | 3Lvごと |

- **武器には強化パスを持たせない**。武器(通常攻撃)の成長は**武器Lv 表だけ**で行う
- E(武器スキル)は武器側のまま。メイン武器を切り替えると E も切り替わる。ただし E の強化パスは別枠にせず、クラス強化と**同じ3Lvごとの候補**に混ぜて出す
- 1つのカテゴリは「1つの要素(スキルなど)」を、3つの強化パスで伸ばす形にする
  - 例: クラススキルなら、威力 / クールダウン / 範囲 の3パス
- **特殊強化(案B)**
  - 各パスが Lv3 に達すると、そのパス固有の派生(特殊強化)が候補に出る
  - 1カテゴリにつき、**3つの派生のうち1つだけ**取れる。取った時点で、残り2つは候補から消える
- **武器の所持**(現行の仕組みを引き継ぐ)
  - 武器枠は **4**(1番目 = メイン武器、固定)。永続ツリー(技巧)の「武器枠」と固有効果「百刃の」で、それぞれ +1(最大 6)
  - 2番目以降は、ラン中に武器カードで拾う**サブ武器**。既存の11種すべてが候補(他クラスのメイン武器である刀・マジックボルトも含む)
  - メイン武器と同じ武器は、サブ武器の候補に出さない
  - E(武器スキル)を持つのは**メイン武器だけ**。サブ武器は通常攻撃(自動)のみ
- **武器Lv**(Q41: `balance/weapons.csv` と同じ方式)
  - 各武器は Lv1〜5 のステータス表(CD / 威力 / 数 / 範囲 など)と、EVO(進化後)の値を持つ
  - 武器カードの候補に、所持している武器それぞれの「Lv +1」が入る。枠が空いていれば「新しい武器」も入る
  - 候補はランダムなので、Lv の上がり方は複数の武器に分散する
  - **メイン武器の進化**: 武器Lv5 かつ クラスLv10 で解放済みなら、「進化」カードが出る
  - **サブ武器の進化**: Lv5 になれば「進化」カードが出る(追加条件なし)
  - 旧仕様の「進化素材(パッシブ)」「宝箱で進化」は廃止する
- 規模の目安
  - 武器系: 4枠 × (取得 1 + Lv +4 + 進化 1) = 最大 24 回。3の倍数以外のLv(3Lvのうち2回)で選ぶので、プレイヤーLv36 前後で取り切る
  - クラス系: 4カテゴリ × 3パス × 3Lv = 36 回 + 特殊強化 4 に対して、3Lvごと = Lv60 で 20 回しか選べない。**全部は取れず、どこを伸ばすかがビルドの分岐になる**

### 3.6 基礎ステータス(共通基準とクラス差)

- 各クラスは、下の**共通基準**からの差で基礎ステータスを決める。対象は 5.3 と同じ16項目
- % 系は加算の補正値で、0% = 等倍(例: 攻撃力 +10% は ×1.1)。乗算系(軽減・クールダウン)は、他の出どころと同じく `(1 - x)` で掛け合わせる
- 共通基準は現行プレイヤーの値に合わせた
- **クールダウンと攻撃速度**
  - クールダウン: 通常攻撃(全ての武器の攻撃間隔)と E / Q の CD に効く
  - 攻撃速度: 通常攻撃(メイン武器)の攻撃間隔にだけ効く。E / Q には効かない
  - クラスLv の共通強化(武器の熟練)のクールダウンは、その武器の攻撃間隔と武器スキル(E)に効く
  - 武器の Lv 表の「攻撃間隔」は、1回の攻撃から次の攻撃までの秒数

|---|---|---|---|---|
| 生命 | HP | 100 | 110 | 80 |

## 4. クラスレベル(永続・クラスごと)

- ラン終了時に、そのランで使ったクラスが**クラス経験値**を得る
  - 獲得量: `討伐数 + 撃破ボス数 × 100`
  - 係数(討伐 1 / ボス 100)は `DATA.classLevel` でデータ化しておき、テストプレイで討伐数を計測してから調整する
- クラス経験値% のステータス(ツリー: 天秤)で獲得量が増える

| Lv | 解放内容 | 種別 | 必要経験値 |
|---|---|---|---|
| 1 | - | | 0 |
| 2 | クラス基礎能力強化 | 専用 | 100 |
| 3 | クラス基礎能力強化 | 専用 | 150 |
| 4 | 専用武器の基礎能力強化 | 共通 | 200 |
| 5 | 専用武器のスキル能力強化 | 共通 | 300 |
| 6 | クラス基礎能力強化 | 専用 | 400 |
| 7 | 専用武器の基礎能力強化 | 共通 | 500 |
| 8 | クラス基礎能力強化 | 専用 | 650 |
| 9 | 専用武器の基礎能力強化 | 共通 | 800 |
| 10 | 専用武器の進化が可能になる | 共通 | 1000 |
| 11 | クラス基礎能力強化 | 専用 | 1250 |
| 12 | 専用武器の基礎能力強化 | 共通 | 1500 |
| 13 | クラス基礎能力強化 | 専用 | 1750 |
| 14 | 専用武器の基礎能力強化 | 共通 | 2000 |
| 15 | メイン武器切り替えの開放 | 専用 | 2500 |
| 16 | クラス基礎能力強化 | 専用 | 3000 |
| 17 | 専用武器の基礎能力強化 | 共通 | 4000 |
| 18 | クラス基礎能力強化 | 専用 | 5000 |
| 19 | 専用武器の基礎能力強化 | 共通 | 7500 |
| 20 | 専用武器のスキル能力強化 | 共通 | 10000 |

- 必要経験値は、そのLvに上がるために必要な量(累計ではない)と解釈した。累計は 42,600
- **メイン武器切り替え(Lv15)**: クラス画面で1番目の武器を、**他クラスのメイン武器**に変更できる。ラン開始時の選択ではない
- **種別**
  - 共通: 武器側の強化。その武器を使うなら、どのクラスでも効く
  - 専用: そのクラスにだけ効く強化
- 武器は、どのクラスが使っても恩恵を受けられる。クラス特性は「通常攻撃」「武器スキル」という形で武器を参照し、特定の武器に依存しない書き方にする
- 各Lvの具体的な強化内容は、クラスの設計ファイルに書く

## 5. 装備

### 5.1 部位・種類・レアリティ

| 部位 | 種類 |
|---|---|

### 5.2 オプション

- 基礎効果(固定で付く効果)はない。オプションはすべて種類の候補からランダムに付き、重複はしない
- 生成時に次の2つをロールする

- レベルアップの**装備カード**で、選んだオプションが +1Lv される(8章。以前の「毎Lv 自動でランダムに1つ」は廃止)

## 7. バトルルール

### 7.1 ダメージ

- 被ダメージ = `max(1, (敵dmg - 防御力) × Π(1 - 軽減%))`
- 敵 dmg の成長率: **+3%/Lv**

### 7.2 敵HP

- 雑魚: `HP(Lv) = 基本HP × 0.2 × (Lv-1) + 基本HP × 1.03^(Lv-1)`(基本HP が 30 の場合 Lv6 で 64.8)
- ボス: 基礎HP はボスごとに **1,500〜2,000**(腐肉の王・巨大スライム 1,500 / 白骨竜 1,700 / ゴーレム 1,900 / 死神 1,800 / カオスドラゴン 2,000)。Lv 倍率は雑魚と共通(`HP倍率 = 0.2 × (Lv-1) + 1.03^(Lv-1)`)
  - 出現時の目安: 1体目(Lv7) 約3,600 / 2体目(Lv15) 約7,300〜8,200 / 最終(Lv23) 約11,400〜12,600
  - 当初案の 750 共通では、最終ボスが旧仕様の約28%まで下がるため変更した

### 7.3 バフ・デバフ

| 名前 | 効果 | 補正 |
|---|---|---|
| 炎上 | 与えたダメージの x% を継続ダメージとして与える | |
| 凍傷 | 1スタックごとに移動速度 -5% | |
| 出血 | 1スタックごとに毎秒最大HPの x% のダメージ | ボス ×1/10、エリート ×1/4 |
| 裂傷 | 1スタックごとに被ダメージ +1% | |

- x の値とスタック上限は、付与するスキル側(クラス設計)で決める
