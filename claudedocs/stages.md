## 2. ステージ

- tierが高いほど、攻撃が激しい敵や状態異常など厄介なものが多い
- 初回クリアされるまでカオス強化は固定される。

### 2.2 出現の候補と間隔(通常モード)

- 出現の候補(3分ごとの区間):

|---|---|---|---|
| 草原 | ゾンビ → コウモリ → スライム | コウモリ・スライム・ブルート | 全部 |
| 荒野 | スケルトン → 弓兵 → 砂術師 | 弓兵・砂術師・投槍兵 | 全部 |
| 森 | 若木 → 森蜂 → リス | 森蜂・リス・クマ | 全部 |
| 晶窟 | コウモリ → 宝石スライム → 晶甲虫 | 宝石スライム・晶甲虫・プリズムフェアリー | 全部 |
| 海淵 | クラゲ → サハギン → ハリセンボン | サハギン・ハリセンボン・チョウチンアンコウ | 全部 |
| 砂海 | サソリ → ハゲワシ → 砂人形 | ハゲワシ・砂人形・アリジゴク | 全部 |
| 奈落 | インプ → ヘルハウンド → マグマワーム | ヘルハウンド・マグマワーム・溶岩スライム・ファイアーメイジ | 全部 |
| 霊峰 | 雪狼 → ゴースト → 氷の精 | ゴースト・氷の精・イエティ・フロストメイジ | 全部 |
| 雲海 | 雷獣の子 → 雷雲 → 対の雷精 | 雷雲・対の雷精・雷の甲冑・サンダーメイジ | 全部 |
| 時計塔 | 歯車 → 時計兵 → 今までの敵 | 時計兵・砂時計の精・今までの敵 | 全部 |
| 王墓 | 毒蜘蛛 → 影の眼 → 腐毒のグール | 影の眼・腐毒のグール・影法師 | 全部 |
| 聖堂 | 光の蝶 → 灯の番人 → 玻璃の天使 | 灯の番人・玻璃の天使・ホーリーメイジ・ファイアー・フロスト・サンダーメイジ | 全部 |

- 時計塔の「今までの敵」(スケルトン・弓兵・溶岩スライム・雪狼・サハギン・晶甲虫)は 1枠のまとまりとして選ばれ、その中から1種が出る
- 砂時計の精はまばらに出る: 選ばれやすさ ×0.25、6体の小集団では出ない、同時に 3体まで(時の歪みが同じ所に重ならないように)
- マグマワームも数を抑える: 選ばれやすさ ×0.6、6体の小集団では出ない、同時に 6体まで(地中では倒せないので増えすぎないように)
- 影の眼はまばらに出る: 選ばれやすさ ×0.5、6体の小集団では出ない、同時に 4体まで(暗闇が続きすぎないように)(仮)
- 腐毒のグールも数を抑える: 選ばれやすさ ×0.6(瘴気の霧が増えすぎないように)(仮)
- 樹人は出現の候補に入れない(若木が育ったときだけ出る)。森蜂は 5匹の群れで出る(3.3)
- アリジゴクはまばらに出る: 選ばれやすさ ×0.6、6体の小集団では出ない、同時に 2体まで(すり鉢が重なりすぎないように)。砂山は出現の候補に入れない(砂人形が倒れたときだけ出る)
- 光の蝶は 4匹の群れで出る(3.3)。天光の聖堂のメイジ 4種(ホーリー・ファイアー・フロスト・サンダー)は tier 3 と同じく少なめ(下のメイジの決まり。ユーザーの答え「少な目で」)
- 対の雷精は 2体の組で出る(1枠で 2体)。6体の小集団では出ない、同時に 6体(3組)まで(線が増えすぎないように)
- メイジ(ファイアー・フロスト・サンダー)は少なめに、1体ずつ出る(2026-10-12): 2つ目の3分から。選ばれやすさ ×0.1(仮)。同時に出現するのは 1体まで(6体の小集団では出ず、大群にも 1体まで)。同時にいられるのは 3体まで(種類ごと。ユーザーの指示「2〜3体ぐらい」)。エリートにならない。試しの計算(2つ目の3分を通す): 立ち止まって倒さないと、奈落は 1分ほどで 3体になってそのまま、雲海はたいてい 2体。20秒ごとに 1体倒すと、奈落はたいてい 2〜3体、雲海は 1体ほど。エスカレーションでは同じ tier のほかのステージの敵として、ほかの属性のメイジも出る(種類ごとに 3体まで)

- 出現の間隔と上限: 1つ目 0.9秒 / 60 → 0.7 / 100 → 0.6 / 130、2つ目 0.5 / 160(90秒から 0.45 / 190)、3つ目 0.42 / 210(90秒から 0.38 / 240)
- 大群: 2つ目・3つ目の3分の 150秒に1回ずつ

### 2.3 曲

- ステージごとのフィールド曲・ボス曲(`music/<ステージ名>-フィールド.mp3`・`-ボス.mp3`。時計塔のボス曲は `-ボス1`(番人・死神の第一形態)・`-ボス2`(終刻の死神。変身で曲が切り替わる))。ボスの曲は、そのボスのステージの曲(エスカレーション・闘技場でも)
- 闘技場は荒野のフィールド曲(曲のファイルがないときは草原の曲で代用)
- 常闇の王墓: `常闇の王墓-フィールド.mp3`・`-ボス1.mp3`・`-ボス2.mp3`。ケルベロスはボス1 だけ(切り替わらない)。影の王は出現でボス1、激昂でボス2 に切り替わる(1秒で。血の夜明けで最初から激昂しているときはボス2 から。エスカレーション・闘技場でも同じ)。影の王が呼んだ影は激昂しないので曲は変わらない。ファイル名の数字は時計塔と同じ半角
- 木漏れ日の森: `木漏れ日の森-フィールド.mp3`・`-ボス.mp3`(女王蜂・古樹の主とも。2026-10-12 に届いた)
- 陽炎の砂海: `陽炎の砂海-フィールド.mp3`・`-ボス.mp3`(大蠍・スフィンクスとも。2026-10-12 に届いた)
- 雷鳴の雲海: `雷鳴の雲海-フィールド.mp3`・`-ボス.mp3`(雷獣・雷神とも。2026-10-12 に届いた)
- 天光の聖堂: `天光の聖堂-フィールド.mp3`・`-ボス1.mp3`(三原の光精)・`-ボス2.mp3`(熾天使)。曲のキーは `f_holy`・`b_holy1`・`b_holy2`(2026-10-13 に届いた。それまでは草原の曲で代用していた)。熾天使のラストラディアンスが終わると曲がフェードアウトする(2.5秒。4.4)
