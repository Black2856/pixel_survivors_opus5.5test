# 仕様書の索引

ゲームの今の仕様。数値・挙動を直すときはここを直し、「調整して」で `js/data.js` などに入れる(仕様書エディタ: `scripts/md-editor/index.html`)。

## どこに何があるか
- `modes.md` — モード(エスカレーション・通常モード・闘技場)・フェーズと時計・闇の霧・宝箱・tier・敵Lv・エリート・出現・カオス強化
- `rules.md` — 戦いの決まり(接触ダメージと被弾・状態異常の効き方・ダメージの決め方・バフとデバフ)
- `stages.md` — ステージの一覧・出現の候補と間隔・曲
- `enemies.md` — 通常敵(値と行動)
- `bosses/README.md` — ボス共通・一覧・技の数 / `bosses/<キー>.md` — ボス 1体ずつ(キーはコードの `js/bosses/<キー>.js` と同じ。死神と終刻の死神は `reaper.md`)
- `classes/README.md` — クラス共通(スキルの共通ルール・スタミナ・ラン中の強化・基礎ステータス・見た目)/ `classes/<クラス>.md` — クラス 1つずつ
- `progression.md` — ラン外の成長(クラスレベル・永続強化ツリー)
- `equipment.md` — 装備(部位・オプション・強化・固有効果・ガチャ)
- `ui.md` — 画面(レベルアップ・ステータス画面・HUD)
- `tower.md` — チャレンジタワーの設計書(1人用は実装済み。仮の値は 4章)
- `coop.md` — 協力プレイ(P2P)の設計書(下書き・実装前。仮の値は 6章)
- `archive/` — 控え(前の案・Q&A の回答記録・実装の段階・終わった計画)。仕様ではない

## 値の決まり
- 距離・速度は内部解像度のピクセル、時間は秒
- 技・攻撃の「×1.2」などは、その敵・ボスのダメージ(敵Lv の倍率込み)に対する倍率
- (仮)の付いた所は仮の値・仮の名前
- 通常敵の日本語名は仮(ゲーム内に表示名はない)
- 値の出どころ: `js/data.js`(`DATA.enemies` / `enemyLevel` / `bosses` / `flow` / `stageRuns` / `arena` / `chaos` / `classes` / `weapons` など)。引くときは `node scripts/dev/data.js <パス>`
