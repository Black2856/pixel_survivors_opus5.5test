# 画面(タイトル・レベルアップ・ステータス・HUD)

## タイトル画面
- 見本はユーザーの絵(claudedocs/img/title.png)。背景の絵は使わず、後ろは今までどおりの草原。メニューは真ん中に(ユーザーの指定)
- 真ん中にロゴ(PIXEL / SURVIVORS / — NOCTURNE —)と、その下にメニューを縦に 1列: 冒険開始(大きく)・協力プレイ・クラス・強化ツリー・装備(新しい装備があれば「NEW n」)・ガチャ。字の前にドットの印(仮: 交差した剣・3人・兜・つながった節・宝箱・宝石の札。印は art.js の `uiIcon`)
- 項目の幅(マウスの当たり)はどれも同じ(一番長い冒険開始の幅)。選んでいる物は金色にして、左に ▶、下に両端が菱形の線、後ろに右へ消える薄いグラデーション(ユーザーの指定)。↑↓(W / S)とマウスを乗せて選び、Enter / Space(クリック)で決める。最初は冒険開始。ほかの画面から戻ると前に選んだ物のまま
- 右上にゴールド、左下に記録(BEST・闘技場。上に飾りの線)、右下にガイド・設定のボタンとキーの説明(↑↓ 選択・ENTER 決定・ESC 戻る。スマホでは出さない)
- 操作の説明の 1行は出さない(仮。ガイドの「操作」にある)

## レベルアップ画面

| 条件 | 表示 |
|---|---|
| 3の倍数のLv | 強化カード 3択(パッシブ / Q / 特性 / E の強化パスと特殊強化を1つの候補にまとめる) |
| 3の倍数以外のLv | 武器カード(新しい武器 / 所持武器の Lv +1 / 進化)と装備カード(装備中のオプション1つ +1Lv。最大Lv まで)を混ぜた3択。1枚ごとに 50% で装備カード(`DATA.equip.cardRate`) |
| 進化の条件を満たした武器がある | 候補に「進化」を確定で1枚入れる |
| 片方を取り切った後 | 残りの枚数はもう片方で埋める |
| 武器カードと装備カードを両方取り切った後 | 3の倍数以外のLv は**微強化**。メニューは出さず、浮き文字で通知だけする |

**微強化の内容**(`DATA.micro`)

| ステータス | 1回あたり |
|---|---|
| 攻撃力 | +1% |
| 最大HP | +1% |
| 移動速度 | +0.5% |
| クールダウン | -0.5% |
| 範囲 | +1% |
| 射程 | +1% |

- クラス強化選択枠(ツリー)で、クラス強化カードの枚数が 3 → 4 に増える
- 武具強化選択枠(ツリー)で、武器カード・装備カードの枚数が 3 → 4 に増える
- リロール回数のステータスで、カードを引き直せる
- 強化カードには、選んだ場合のステータスの変化を「現在値 → 選択後」で表示する

## ステータス画面

**開き方**

| 場面 | 開き方 | 備考 |
|---|---|---|
| ラン中 | **Tab** で開く / 閉じる。ポーズ画面(Esc)からも開ける | 開いている間はゲームを一時停止する |
| ラン外 | クラス画面・装備画面にパネルとして常に表示する | 装備やメイン武器を変えると即座に反映する |

**タブ構成**

| タブ | 内容 | ラン中 | ラン外 |
|---|---|---|---|
| ステータス | 全ステータスの最終値。生命 / 技巧 / 天秤 / 特殊 の4グループに分けて表示 | ○ | ○ |
| スキル | 通常攻撃・E・Q・Space の、実際の CD(クールダウン適用後)・威力倍率・スタミナ消費 | ○ | ○ |
| 装備 | 3部位の各オプションの「現在Lv / 最大Lv」と、現在の値 / 最大時の値。固有効果 | ○ | ○ |
| ビルド | 取得した強化(カテゴリごとのパスLv、特殊強化)、武器Lv、微強化の累計 | ○ | - |

**ステータスタブの表示**

- 1行 = 1ステータス。最終値を大きく表示する
- 行を選ぶ(マウスを乗せる)と、**内訳**を表示する

| 内訳の項目 | ラン中 | ラン外 |
|---|---|---|
| クラス基礎 | ○ | ○ |
| 永続ツリー | ○ | ○ |
| クラスLv | ○ | ○ |
| 装備(オプション) | 現在Lv の値 | 「開始時 0」と「最大時」の2列 |
| 固有効果 | ○ | ○ |
| ラン中の強化 | ○ | - |
| 微強化 | ○ | - |

- ラン外では全オプションが Lv0 なので、「開始時」と「装備成長の最大時」の2列を並べて、装備の強さが見えるようにする
- 乗算系(軽減・クールダウン)は、最終値を「-23.4%」のように実際の効果量で表示する

**ヘッダー**(全タブ共通)

- クラス名とクラスLv、メイン武器と武器Lv
- ラン中はさらに、プレイヤーLv とクラス特性の状態(剣気 / 魔力結晶 など)

**計算**

- ステータスは、出どころ(source)ごとの値を持ったまま合算する関数1つで計算する
  - ゲームの計算と画面の内訳表示で、同じ関数を使う
  - 表示と実際の値がずれないようにするため

## HUD(左下のステータスパネル)

HP・スタミナ・クラスリソース・E / Q を、**左下の1つのパネル**にまとめる。

```
┌────────────────────────────────────────────┐
│ ◆SAMURAI Lv12                               │
│ ╱██████████████████▓▓░░░░░░╱  86 / 110  HP  │  ← 平行四辺形のバー
│ ╱██████████░░░░░░░░░░░░░░░╱          STA   │
│ ╱▰▰▰▰▰▰▰▰▱▱▱▱▱▱▱▱▱▱▱▱▱▱▱╱  剣気 42         │
│                          [E 乱れ桜] [Q 居合] │  ← CD は円形のスイープ
└────────────────────────────────────────────┘
```

**各要素**

| 要素 | 見せ方 |
|---|---|
| 枠 | ピクセル調の金属フレーム + クラスの色のアクセント線。上部にクラスの紋章とクラス名 / クラスLv |
| HP バー | 一番太い。平行四辺形(斜めに切ったバー)。数値は `86 / 110` |
| | 被弾: 白い「遅れて減るバー」を残す(ボスHPバーと同じ仕組み) |
| | 回復: 緑に一瞬光る |
| | 残り 30% 以下: 赤く脈打ち、枠も赤く点滅する |
| スタミナバー | HP より細い。防御スキル1回分の消費量ごとに目盛りを付ける(消費 75 なら 75 ごと) |
| | 使えないとき(消費量に足りない)は暗い色 |
| | ガード後の回復停止(5秒)の間は灰色 + 斜線が流れ、残り時間を細い線で表示する |
| クラスリソース | クラスごとに専用の見た目(下表)。満タンや発動可能な状態では光らせる |
| E / Q アイコン | キー表示付きの四角いアイコン。CD 中は暗くして円形スイープで残りを表示する |
| | 使えるようになった瞬間に、白く光るリングを1回出す。自動発動の設定のときは「AUTO」の小さな札を付ける |

**クラスリソースの表示**

| クラス | リソース | 表示 |
|---|---|---|
| サムライ | 剣気 0〜100 | 刃の形のゲージ。満タンで赤い炎のようなオーラが揺れ、「満」の文字が出る |
| メイジ | 魔力結晶 0〜5 | ひし形の結晶アイコンを5つ並べる。溜まると1つずつ光って点灯する |
| | 元素循環 | 結晶の横に、次の属性(炎 / 氷 / 雷)の小さなアイコン。攻撃ごとに回転して切り替わる |

- ほかのクラスのリソースの表示は、各クラスの設計ファイルの「見た目」

**その他**

- 配置: 左下、画面端から 16px。スマホ幅ではパネル全体を縮小する
- 上部の武器スロット、右上のカウンター、右側のコンボ表示は今の位置のまま
- 敵の攻撃が画面の左下に来ても見えるように、パネルの背景は半透明にする。プレイヤーがパネルの裏に入ったときは、パネル全体を薄くする
- DOM(HTML/CSS)で作る。ステータス画面と同じ計算関数から値を読む

## UI の大きさ

- HUD とメニュー画面は、窓の大きさに合わせて拡大縮小する。高さは 720 を 1倍として合わせる。幅は 1280 を超えた分だけ大きくし、900 以上なら縮めずに狭い組み方に切り替え、900 未満で幅に合わせて縮める(どちらも 0.5倍まで)
- 設定の「UIサイズ」(50〜150%)は、窓に合わせた大きさに掛ける倍率。100% で全ての画面が窓に収まる。120% までは収まり、それより大きいとタイトル・ガチャ・設定などのメニュー画面はスクロールになる
- 狭い窓の組み方(装備・クラスを1列にするなど)は、拡大した後の幅で切り替える(1140 / 820 / 760)
- 左下のステータスパネルも、ほかの HUD と同じ割合で大きくなる
- 宝箱・ガチャを引いた画面はスクロールできないので、窓の高さ ÷ 680 を上限にする(設定の倍率を大きくしても窓に収まる)

## スマホ

**スマホとして扱う端末**
- 主な入力が指で、マウスを乗せられない端末(CSS の `(hover: none) and (pointer: coarse)`)。窓の大きさでは決めない(PC の小さい窓は今までどおり)
- タッチパネルの PC(マウスもある)は今までどおり

**画面の向き**
- 横向きで遊ぶ。縦向きのときは「横向きにしてください」を画面いっぱいに出し、ラン中ならポーズする
- 冒険開始を押したときに全画面にして横向きに固定する(できる端末だけ。Android の Chrome など。iPhone はできない)

**大きさ**
- メニュー画面・説明の吹き出し・帯: 窓に合わせた大きさが 0.85倍より小さいときは 0.85倍にする(文字が 11px 以上になる)。入りきらない画面はスクロール
- HUD: 0.7倍より小さくしない(ゲームの画面を隠しすぎないように)
- 設定の UIサイズの倍率は、どちらにも掛ける
- タッチのボタンは窓の大きさに関係なく同じ大きさ(指の大きさ)。防御 72px・E / Q 56px・ポーズ 44px。UIサイズの倍率は掛ける
- 宝箱・ガチャを引いた画面は、上の上限で窓に収める。スマホでは 0.55〜0.6倍になり、カードの中の文字は小さい
- タイトルのロゴは窓の高さでも小さくして、スクロールせずに収める
- 強化ツリー・ガチャは縦に積まない(高さが足りないため。拡大した後の幅が 760 より広いとき)。レベルアップ画面も、入りきらないとき(667×375 など)はスクロール
- ゲームの画面(見える範囲)は変えない。高さ 390 の端末では縦に 195 ドット見える(PC の 1280×720 は 240)

**ラン中の操作**

| 操作 | タッチ |
|---|---|
| 移動 | ボタン以外の所に指を置いて動かす(置いた所が中心のスティック。40px 動かすと最大の速さ) |
| 防御スキル(SPACE) | 右下の大きいボタン。押している間は長押しと同じ |
| E / Q | 防御のボタンの左と上の丸いボタン。CD の残りを円で出す。自動発動の設定はそのまま |
| ポーズ(ESC) | 右上の「II」ボタン。ステータス(TAB)はポーズ画面から |
| マウス照準(SHIFT) | なし(いつも自動照準) |
| レベルアップ | カードをタップで選ぶ。リロール・スキップはボタン |

**マウスを乗せる操作の代わり**
- 説明の吹き出し(用語・武器・状態異常・設定の行): タップで出し、ほかの所をタップすると消す。カードの中の用語をタップしたときは、カードを選ばない
- ステータス画面の内訳: 行をタップ
- 画面を替えたら吹き出しは消す
- マウスを乗せたときの見た目の変化(ボタンが浮く・光る)は出さない(指を離した後も残るため)

**表示の文**
- ボタンのキーの表示(「(ESC)」「(TAB)」「(R)」「(SPACE)」「(Enter)」)は出さない
- キーとマウスの操作の説明(レベルアップ・宝箱・ガチャ・ステータスの内訳・強化ツリーの拡大・ガイドの操作)は、タッチの言い方にする

**ブラウザ**
- ノッチ・角の丸い所に HUD とボタンがかからないように、画面の端からの位置にセーフエリアを足す
- ダブルタップの拡大・長押しのメニュー・引っぱって読み直す動きをさせない
- 画質の既定は変えない(高)。描画は CSS の画素の数で作るので、844×390 は 1280×720 の 36% の画素。重ければ設定で下げる
