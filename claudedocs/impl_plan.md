# 実装計画: クラス & 装備システム

- 作成日: 2026-09-29
- ブランチ: `feature/class-equipment`
- 仕様: `claudedocs/design_class_equipment.md`(v5)、`claudedocs/classes/*.md`

---

## 方針

- **各フェーズの終わりで、ゲームが最後まで遊べる状態を保つ**。途中で壊れたまま次に進まない
- 各フェーズの終わりにブラウザで確認してからコミットする(フェーズ内でも区切りのよいところでコミット)
  - 確認の中身: コンソールエラーなし / 1ラン通しプレイ / 追加機能の動作
- 今は素の `<script>` 構成(ビルドなし)。これを維持し、`world.js`(1461行)がこれ以上膨らまないよう、新しい仕組みは**別ファイル**に分ける

### 追加するファイル

| ファイル | 役割 | 読み込み順 |
|---|---|---|
| `js/stats.js` | ステータス計算(出どころ別の内訳を保持)、ダメージ式 | core.js の後 |
| `js/classes.js` | クラスのランタイム(特性・パッシブ・Q・防御スキル・スタミナ)、E の実行 | world.js の前 |
| `js/equip.js` | 装備の生成・ロール・強化・売却、インベントリ、ラン中のオプション成長 | stats.js の後 |
| `js/meta-ui.js` | ラン外の画面(ステージ選択 / クラス画面 / 装備 / ツリー / ショップ) | ui.js の後 |

## フェーズ1: 土台(ステータス計算とセーブ)

**目的**: 新しいステータス体系とセーブ形式に置き換える。見た目の変化はほぼない

| 作業 | ファイル |
|---|---|
| `DATA` に追加: `classes`(サムライの基礎ステータスのみ)、`classLevel`、`tree`、`affixes`(ロール範囲)、`rarity`、`uniques` | data.js |
| `computeStats()` を新設。出どころ(クラス基礎 / ツリー / クラスLv / 装備 / 固有効果 / ラン中強化 / 微強化)ごとに値を持ち、合算する | stats.js |
| `recalc()` / `dmgMul()` / `critRate()` を `computeStats()` 経由に置き換える | world.js |
| ダメージ式: `max(1, (敵dmg - 防御力) × Π(1 - 軽減%))` | world.js(`hurtPlayer`) |
| 敵HP: `基本HP × 0.2 × (Lv-1) + 基本HP × 1.03^(Lv-1)`、敵dmg +3%/Lv、ボスの基礎HP 750 に統一 | data.js / world.js |
| `META` を v2 形式に(`ver: 2`)。旧 `META.up` はゴールドに全額返金、`best` / `runs` は引き継ぐ | core.js |
| `META` v2 の中身: gold / tree / classes{lv, xp, weapon} / inventory / loadout / best / runs / stageClear | core.js |

**完了条件**
- 旧セーブを読み込むと返金され、エラーが出ない
- サムライの基礎ステータスで、今までどおり1ラン遊べる(武器・パッシブはまだ旧仕様のまま)
- コンソールから `computeStats()` の内訳を確認できる

## フェーズ2: 戦闘(サムライ1クラスで遊べる状態)

**目的**: 新しい戦闘とレベルアップの流れを完成させる

| 作業 | ファイル |
|---|---|
| 入力: Space(防御) / E / Q / Tab。固定ダッシュを削除 | core.js / main.js |
| スタミナ(基礎100、回復20/s、ガードは被ダメ分を失い5秒停止) | classes.js |
| サムライ: 剣気、残心、居合(Q)、見切り(Space)。予備動作・演出込み | classes.js |
| メイン武器: 1枠目に固定の刀、E「乱れ桜」 | world.js / classes.js |
| サブ武器: 既存11種(メイン武器と同じものは除外)、武器枠4 | world.js |
| レベルアップ: 3の倍数 = クラス強化(パッシブ / Q / 特性 / E の強化パスと特殊強化)、それ以外 = 武器カード、取り切った後 = 微強化 | world.js / ui.js |
| 進化: メイン武器は Lv5 + クラスLv10、サブ武器は Lv5 のみ。進化素材(パッシブ)の条件を削除 | world.js |
| 削除: パッシブ、アーティファクト、通常の宝箱 | data.js / world.js / ui.js |
| 状態異常: 出血(ボス ×1/10、エリート ×1/4)を追加 | world.js |
| HUD: 左下のステータスパネル(HP / スタミナ / 剣気 / E・Q)。足元のバーを削除 | ui.js / index.html / css / render.js |
| 設定: E / Q の自動発動 | ui.js |

**完了条件**
- サムライで1ランをクリアまで遊べる
- レベルアップの流れ(3の倍数 / それ以外 / 微強化)が仕様どおりに動く
- E / Q の予備動作と演出、見切りのジャスト判定、剣気の増減が動く

## フェーズ3: 装備

**目的**: 装備を手に入れて、付けて、ラン中に成長させる

| 作業 | ファイル |
|---|---|
| 装備の生成: 部位・種類・レアリティ(50/30/14/5/1%)、オプション(v と最大Lv 3〜5)、レジェンダリーの固有効果と二つ名 | equip.js |
| ラン中の成長: 毎Lv、未最大のオプションから1つを +1Lv(Lv0 開始)。通知を出す | equip.js / world.js |
| 固有効果17種の実装 | equip.js / stats.js / world.js |
| ボス撃破で装備宝箱(枠数 70/25/5%)。今の宝箱演出を流用する | world.js / ui.js |
| ラン終了時の報酬(撃破ボス数に応じて0〜2個、クリアで +1)とクラス経験値(`討伐数 × 0.3 + ボス × 100`) | main.js |
| インベントリ(上限1000)、ロック、一括売却、強化(1オプション +20〜30%、回数上限はレアリティ別) | equip.js |
| 装備画面(簡易版): 3部位の付け替え、一覧、ロック / 売却 / 強化 | meta-ui.js |

**完了条件**
- ボス撃破で装備が手に入り、ラン終了後に付け替えられる
- 付けた装備のオプションがラン中に育ち、ステータスに反映される
- 強化・売却・ロックが動き、再読み込みしても保存されている

## リスク

| リスク | 対策 |
|---|---|
| セーブ移行の失敗で、既存のゴールドが消える | 移行前の旧データを `ps55_meta_v1_backup` に残す |
| インベントリ1000個分のセーブ容量 | 1個 約150バイトとして約150KB。localStorage の上限(約5MB)に収まる。オプションは短いキーで保存する |
| `world.js` の肥大化 | 新しい仕組みは追加ファイルに書き、world.js は呼び出しだけにする |
| フェーズ2で壊す範囲が大きい(パッシブ・アーティファクト・宝箱の削除) | 削除より先に新しい流れを作り、切り替えてから削除する |
