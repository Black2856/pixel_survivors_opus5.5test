# ボス: 冥犬ケルベロス

王の墓を守る三つ首の番犬。左が毒の首、真ん中が牙の首、右が闇の首。合体形態(三つ首の犬)と分裂形態(首が1本ずつの影の犬 3匹)をくり返し、分裂している間に、どの犬(首)から倒すかを選ぶ。プレイヤーへまっすぐ(速度 21)

- 形態: 合体形態と分裂形態をくり返す
  - 合体形態で 15秒(激昂 11秒)たつと分裂する。技の最中なら終わってから(仮)
  - ★分裂: 1秒。体が黒い炎に包まれ、影になってほどける → 毒の犬・牙の犬・闇の犬が 3方向へ跳び出す(本体の位置から 70。牙の犬はプレイヤーの方へ、毒・闇の犬は ±120° へ)(仮)
  - 分裂している間、本体は消える(攻撃が当たらない・触れても当たらない。自動の照準は犬を狙う)。12秒たつと合体する(仮)
  - 合体: 1秒。生き残った犬が、そのときのプレイヤーの位置(動かない)へ跳び込む(円 半径 50)→ ×1.2・外へ 60 押す。そこにケルベロスが戻る(仮)
  - 12秒のうちに 3匹とも倒すと、合体できずに最後の犬の場所で倒れ込む(5秒。動かず技も使わない。被ダメ ×1.5)。起き上がると首が全部生え直す(仮)
- 首と犬:
  - 合体形態では首を壊せない(ダメージは体だけに入る)(仮)
  - 犬の HP は最大HP の 30%。犬へのダメージは本体にも ×0.2 入る(犬の残りHP まで。とどめの余りは入らない)(仮)
  - 犬を倒すと、その首が壊れる。合体したときは付け根だけになり、その首の技を使わない。壊れた首は次の分裂で生え直す(その犬は HP 満タンで出る)。倒されなかった犬の HP は次の分裂に持ち越す(仮)
  - どの犬から倒すかで、次の合体形態の攻め方が変わる: 牙の犬を倒すと影の突進がなくなり、近づく手段が減る。闇の犬を倒すと闇の遠吠えと影の猟犬がなくなる。三獄の息吹・三獄の魔弾・三獄の雨は、倒した犬の首の属性(毒の首 = 毒・牙の首 = 炎・闇の首 = 氷)を使わなくなる(息吹のダメージも首の数だけ下がる)
  - 犬は経験値・報酬なし。撃破数・復讐の連鎖に数えない。触れると ×0.6(仮)。犬の速さは、本体と同じく敵Lv と激昂で上がる
  - 新しい仕組みなので、そのランで初めて見たときに一度だけ説明が出る(`../rules.md`)

## 補足

- 合体形態の首は壊せる物ではなく、体と一緒に描く(胸から首の線が伸び、その先に頭)
- 分裂の構えでは体と首が黒い影に染まり、黒い炎に包まれて震える
- 分裂の瞬間は紫の光の柱が立ち、緑・赤・紫の光の筋が 3方向へ走って、その先に犬が着地する
- 分裂の間、本体は消える(ダイブ中の海竜と同じ)
- 犬は本体の持ち物として作るので、影の王の影として呼ばれたときも、影を倒せば犬も消える(影のケルベロスも分裂・合体する。犬の HP は影の HP から)
- 犬と瘴気の雨の落ちる所は闘技場の壁の中に収める
- 合体は、犬が首の色の残光を引いて跳び込み、跳び込む先で闇が渦を巻いて縮み、紫の光の柱と衝撃波とともにケルベロスが現れる
- 影の突進の影は、赤い縁のケルベロスの影絵が紫の残像を引いて駆け抜ける(本体は赤い残像)
- 帯は毎回、そのときのプレイヤーへ向け直す
- 最後の切り裂きは赤黒い全周の斬撃で ×1.0(仮)
- 影の猟犬の目は予告ではなく演出なので暗闇でも見える(赤い帯は暗闇では見えない。王墓の決まり)
- 影の猟犬は赤い縁の犬の影絵に赤い目で、走った跡に黒紫のもや
- 三獄の息吹は、毒の首 = 毒 +1、牙の首 = 炎上(ボスのダメージ ×0.1)、闇の首 = 凍傷 +1
- 扇を首の数に分けて、それぞれの属性の色(毒 = 緑・炎 = 橙・氷 = 青白)で塗り、構えの間は口から属性の煙がこぼれる
- 2秒 吐き続け、扇は毎秒 0.6rad でプレイヤーを追う(仮)
- 三獄の雨の弾は、ケルベロスから 150 の所(プレイヤーの方向を中心に 毒の首 -75°・牙の首 0°・闇の首 +75°)に落ち、その首の属性の霧(半径 100)になる
- 霧は 0.5秒ごとに、毒の霧 = 毒 +1・炎の霧 = 炎上(ボスのダメージ ×0.1)・氷の霧 = 凍傷 +1(ダメージはない)
- 霧と弾の色は属性ごと(毒 = 緑と紫・炎 = 橙・氷 = 青白)
- 三獄の魔弾は、首ごとにその属性の玉を口から撃つ
- 闇の玉(影の眼)と同じく、プレイヤーに 50 まで近づくか、撃って 4秒で、プレイヤーの方向へ割れる(0.2rad おき・2.5秒)(仮)
- 闇の犬の影だまりは、地面の黒い楕円(紫の縁)と光る目 2つが滑るように迫り、飛び出す前は広がって紫に光る
- 犬の HP バーは壊せる物の決まり(`../rules.md`)どおり金色
- 技は1つずつ使う(仮)
