# ボス: 三原の光精

#### 三原の光精(聖堂 1体目)

白い水晶の核(中で赤 → 緑 → 青と色が巡る)のまわりを、赤・緑・青の灯(光の玉)が回る光の精。色の光で状態異常を付け、光が重なった所は色が混ざって効果も混ざる。距離 110 を保って漂い、ゆっくり横へ回り込む(ときどき向きを変える。速度 16)。段階10(2026-10-12。Claude の案。ユーザーの原案は「光の三原色をテーマにした敵」)

- 色の決まり(ユーザーの案): 赤 = 出血 +1 / 緑 = 毒 +1 / 青 = 疲労(3秒)/ 赤+緑(黄)= 痺れ +2 / 赤+青(紫)= 炎上(ダメージ × 0.1・3秒)/ 緑+青(水色)= 凍傷 +2 / 赤+緑+青(白)= 乱光 +2

| 技 | 種類 | 間隔(激昂) | 予告 | 内容 |
|---|---|---|---|---|
| ★三原の灯 | 範囲(追う円)・状態異常 | 14(11)、初回 3 | 0.6秒(灯が飛んで円を灯す。この間は当たらない) | 赤・緑・青の光の円(半径 50)が、プレイヤーのまわり 3方向(120° おき・110 離れた所)から、それぞれ違う速さ(赤 50・緑 38・青 28)でプレイヤーを追う(6秒。激昂 8秒)。円の中にいると 0.5秒ごとに、その場所の色の効果(1色 ×0.1・2色 ×0.3・白 ×0.6 と、色の状態異常)。止まっていると 3つが重なって白になる。円の重なりから出て、色を分ける |
| 白の収束 | 範囲(集まる円) | 10(8)、初回 9 | 2秒。灯の動く円(半径 40)が集まる道すじ。最後の 0.6秒は真ん中の 円 半径 50(出たら動かない) | 3つの灯がプレイヤーのまわり 3方向(120° おき・100 離れた所)に降り(0.4秒)、1.6秒かけて真ん中へ集まる。真ん中はプレイヤーを追う(速さ 30。真ん中の円が出たら止まる)→ 白の爆発(半径 50)×1.4・乱光 +2。少し動いて止まると追いつかれるので、早めに離れる |
| 三原の柱 | 範囲・状態異常 | 7(5.5)、初回 6 | 各 1秒。プレイヤーが 0.6秒後にいる所(今の歩きのまま進んだ所。先読み)に 円 半径 30 | 赤 → 緑 → 青の順に 0.5秒おき、光の柱 ×0.6 とその色の状態異常。まっすぐ歩き続けると当たる。円が出るたびに同じ向きへ曲がる(回るように歩く。引き返す・左右に振ると前の円に戻って 1回当たる)。止まっていると 3本が重なって白で乱光 +2 |
| 分光 | 弾 | 5(4)、初回 2 | なし | 白い光の玉 3発(扇 ±0.3rad・速さ 75)。0.6秒後に、それぞれ赤・緑・青の 3つに割れて扇に広がる(±0.3rad・速さ 90、×0.5・その色の状態異常)。割れる前の白い玉は ×0.5・乱光 +2。3回(0.7秒おき) |
| ミラーボール(激昂で追加) | 範囲(動く光)・状態異常 | 終わってから 20、激昂から 4 | 光精の頭上 150 の高さにミラーボールが現れ、0.6秒で光の先が地面に届く。そのあと 1秒は弱い光(真下で 3色が重なった白い円。縁は 3色が交互の点線。当たらない) | 光精の頭上 150 の高さにミラーボールが浮かぶ(壊せない。ふだんは画面の上の端の外で、光が上から差し込む。プレイヤーが光精より北にいると見える)。赤・緑・青の光が 360° を 3等分した向き(120° おき)に出て、回りながら(毎秒 20°)、傾きが sin のように上下する(5秒で 1往復。3つ同じ傾き。真下 → 楕円の遠い縁が 325 の所まで)。光はヘヴンズリフトと同じ円錐(高さ 150・真下の円は半径 66(開きの半分 23.7°)、上がると最大 277×191 の楕円)。真下では 3色が重なって白になり、上がると赤・緑・青に分かれて広がる。光が重なった所は色が混ざる(黄・紫・水色・白)。楕円に入っていると 0.5秒ごとに重なっている毎に ×0.2、0.4、0.7 と、その場所の色の効果(三原の灯と同じ。1色・2色はその色の状態異常、3色が重なった白は乱光 +2)。光と光の間に入る。15秒で消える。その間も光精は動き(距離 110 を保って横へ漂う。玉と光は付いてくる)、ほかの技(三原の灯も)を使う。三原の灯の円と重なった所も色が混ざり、効果はその場所の色(ダメージはそれぞれの倍率) |

- 技は 1つずつ使う。技のあとは少しあける(三原の灯 1.2秒・白の収束 2.4秒・三原の柱 2.2秒・分光 1.8秒・ミラーボール 1秒。三原の灯の円・分光の弾・ミラーボールは次の技と重なる)
- ユーザーが仕様書で直したもの: 激昂 60%(2026-10-12)。三原の柱の予告 0.6秒 → 1秒・柱の間 0.4秒 → 0.5秒、スポットライトの開き 5.1° → 20°・×0.6 → ×0.5・8秒 → 15秒・間隔 14 → 20(2026-10-12)。スポットライトの台の距離 100 → 150・重なっている数で ×0.1 / ×0.3 / ×0.5(2026-10-13)。三原の灯 ×0.3 / ×0.5 / ×0.8 → ×0.1 / ×0.3 / ×0.6・ミラーボール ×0.1 / ×0.3 / ×0.5 → ×0.2 / ×0.4 / ×0.7(2026-10-13)
- 白の収束は実装したあと、ユーザーの案で真ん中がプレイヤーを追うようにした(2026-10-12。白光・三原の柱と同じような攻撃で単調に見えるので。`enemies_history.md` の 7.6)。追う速さ(30。白光の柱の 45 より遅く)・止まる時(真ん中の円が出た時)・集まる時間(1.2秒 → 1.6秒)は決めた値。まっすぐ走って逃げてよけられる反応は、前(0.65秒まで)と同じくらい(0.75秒まで)にした
- 三原の柱は実装したあと、ユーザーの案で移動を先読みするようにした(2026-10-12。`enemies_history.md` の 7.6)。先読みは歩きの速さ(押し流し・ダッシュは入れない)で 0.6秒先(予告の長さと同じ)。初めて見たときの説明を足した
- 白光は実装したあと、ユーザーの案で外して、スポットライトにした(2026-10-12。`enemies_history.md` の 7.6)。ユーザーが決めたもの: 台 3個・HP 各 12%・ヘヴンズリフトの照射の仕組み・光精とプレイヤーの間あたりを動き回る。作るときに決めたもの: 白い光と乱光(白光の代わりなので。赤・緑・青の光にすると三原の灯と同じになる)・台の置き方(光精のまわり 56。プレイヤーの方から ±60° と真後ろ)・光の高さ 39 と開き 5.1°・照らす所の速さ 40・次に照らす所の 4割はプレイヤーの所・台から 130 まで・弱い光 1秒・8秒で消える・間隔(終わってから 14)・その間 光精は動かず、ほかの技を使わない(白光と同じ)。開き・×0.6・8秒・14 はあとでユーザーが直した(上)。開きが 20° になると、狙う所(円錐の軸)を台から 130 まで動かすと傾き + 開きが 90° を超えて光が地面に届かない(楕円にならない)ので、「台から 130 まで」はヘヴンズリフトと同じく楕円の遠い縁のこととした(狙う所は台から 52 まで。楕円は最大 104×54)。真後ろの台はプレイヤー(光精から 110)まで届かない
- スポットライトはそのあと、ユーザーの案で台を離して置き、少しずつプレイヤーの方を向き、赤・緑・青の光にした(2026-10-13。`enemies_history.md` の 7.6。上の「白い光と乱光」「光精のまわり 56」「光精とプレイヤーの間を動き回る」はこれで変わった)。作るときに決めたもの: 置き方(プレイヤーのまわり 100。光精の方から ±100° と真後ろ。±60° だと光精のそばまで届いて、近づいて戦うと当たり続けた)・回る速さ 毎秒 12°(プレイヤーの所で 21。歩き 55 より遅く)・始めの向きのずれ 60°(止まっていると 5秒で当たる)・傾きの速さ 30・色の効果は三原の灯と同じ(前の「乱光 +1」の代わりに、3色が重なった白で乱光 +2)・×0.5 はそのまま・三原の灯の円が消えてから使う(色の光どうしは混ざらないので重ねない)。そのあとユーザーの案で、光とプレイヤーが離れているほど速く向くようにし、最長距離を 2.5倍(130 → 325)にした(2026-10-13)。作るときに決めたもの: 「離れているほど」は光の向きとプレイヤーの向きのずれのこと(台からプレイヤーまでの距離にすると、遠いプレイヤーほど光が速く横切って走っても逃げられない)・回る速さ = ずれ × 0.8 /秒(毎秒 60° まで。走ると 69 遅れるので、楕円の幅の半分 45 の外にいられる)。最長距離が 325 になって光精のそばにも届くので、「光精の側は空ける」はなくなった(横の台の ±100° はそのまま)
- スポットライトはそのあと、ユーザーの案でミラーボールに変えた(2026-10-13。`enemies_history.md` の 7.6。台・プレイヤーの方へ向く動きはなくなった)。ユーザーが決めたもの: 頭上 250 の高さに浮かぶ(聞いて決めた。玉はふだん画面の上の外)・壊せない・3色を 360° で 3等分・回りながら sin のように上下。作るときに決めたもの: 開きの半分 20° → 6°(高さ 250 から 20° だと真下の円が半径 91 になるので。聞いたときに 5〜6° と伝えた)・回る速さ 毎秒 20°(光精から 110 の所で 38 < 歩き 55)・上下の 1往復 5秒・3つの傾きはそろえる(真下で 3色が重なって白、上がると赤・緑・青に分かれる)・上の端は前の最長距離 325(遠い縁)・玉のデザイン(鏡のかけらの玉と金の輪と 3つの灯)。試した値では、止まっていても当たるのは 15秒で数回(光精から 110 で 0〜2回、40 で 2〜5回)・光と光の間に入ると 0回で、弱め。そのあとユーザーの案で、高さ 250 → 150・真下の円の半径を 3倍(26 → 78。開きの半分 6° → 27.5°)にした(2026-10-13)。「半径」は前の報告の「真下の円の半径 26」のことと読んだ。強くなった: 光精から 40 で止まると 15秒で 23〜26回(白 10〜11)、110 で 14回、200 で 6〜10回、300 で 0回、光と光の間に入ると 0〜3回。そのあとユーザーの案で、大きさを 85% にし(真下の円の半径 78 → 66。開きの半分 23.7°。楕円は最大 277×191)、出ている間も光精が動いてほかの技を使うようにした(2026-10-13)。作るときに決めたもの: 「サイズ」は真下の円の半径のこと(楕円の遠い縁 325 は届く遠さなので変えない)・三原の灯も使う(前は色の光どうしが混ざらないので重ねなかった。灯の円と楕円を 1回で塗って色を混ぜ、効果もその場所の色にした)・出して 1秒はほかの技を使わない・終わったあとの 1秒の間はなくした。試した値(15秒): ほかの技を止めると、止まっていて 9〜12回(光精が距離 110 に戻るので、40 から始めても 10〜16回・白 1回)、光と光の間に入ると 0〜2回、離れていくと 0〜1回(光精は遅い)、よけると 6〜11回。ほかの技も使うと、その 15秒に分光・三原の柱・三原の灯・白の収束を合わせて 7回使い、灯の円と光が 7.4秒重なった
- 原案(`enemies_history.md` の 7.6)から変えたもの・作るときに決めたもの: 三原の灯の円は、灯がプレイヤーのまわり 3方向へ散ってから追う(最初から重なって白にならないように)。三原の柱の白は「3回当たったか」ではなく居場所で決める(柱は 0.4秒おきで、被弾後の無敵より短いので 3回は当たらない。0.5秒おきの今も、無敵と同じ長さなので 3回目までは当たらないことがある)。三原の柱のよけ方の説明は、予告 1秒・0.5秒おきにしたとき「引き返すのが確か」から「同じ向きへ曲がる(回るように歩く)」に変えた(予告が柱の間より長いので、引き返すと前の円に戻って 1回当たる)。技の間隔・初回・技のあとの間・灯の速さ・柱の間隔・分光の扇と速さは作るときに決めた(表)

実装メモ: 色の円は、1点ごとにどの円に入っているか(赤 1・緑 2・青 4 のビット)で色を決め、混ざった色をそのまま淡く重ねる(明るい床に足し合わせると白に寄って色が見えないので。重なった所は 黄・紫・水色・白。白は少しまたたく)。縁は回る光の点(灯の色と白)。灯は円の上に浮かび、円を照らす光の筋を落とす。白の収束の道すじの円は当たる瞬間の白い光(1.4)を出さない(4つの円の光が重なって赤い塊に見えるので。当たる真ん中の円だけ光る)。ミラーボールは render.js で 1点ずつ描く(drawTriBall): 鏡のかけらを貼った玉(経度・緯度でかけらに分け、目地は暗く、左上からの光で明るさを変える。回るにつれてかけらが横へ流れ、ときどき赤・緑・青・白にきらめく)と、まわりを回る金の輪と赤・緑・青の灯(光精の灯と同じ)。聖堂の明るい床で白く飛ばないように、一番明るいかけらもくすませる。光はヘヴンズリフトと同じ計算(coneSpot)と空中の円錐の描き方(drawConeShaft。その光の色で、照らしている間は縁がその色の線、弱い光の間は点線)。地面の楕円(当たる所)は三原の灯の色の円と同じ塗り方(drawTriZones。1点ごとにどの楕円に入っているかで混ざった色を決める)。三原の灯と同時なら、円と楕円を合わせて 1回で塗る(重なった所も色が混ざる。弱い光の方は淡く)。光精の照らす光は弱く(明るい床で光芒が白く飛ばないように)。地面の楕円の色は画面の中だけ塗る。三原の灯・白の収束・三原の柱・分光・ミラーボールは、そのランで初めて見たときに一度だけ説明が出る(1.13)
