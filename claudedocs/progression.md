# ラン外の成長(クラスレベル・永続強化ツリー)

## クラスレベル(永続・クラスごと)

- ラン終了時に、そのランで使ったクラスが**クラス経験値**を得る
  - 獲得量: `討伐数 + 撃破ボス数 × 100`
  - 係数は `DATA.classLevel`(討伐 1 / ボス 100)
- クラス経験値% のステータス(ツリー: 天秤)で獲得量が増える

| Lv | 解放内容 | 種別 | 必要経験値 |
|---|---|---|---|
| 1 | - | | 0 |
| 2 | クラス基礎能力強化 | 専用 | 100 |
| 3 | クラス基礎能力強化 | 専用 | 150 |
| 4 | 専用武器の基礎能力強化 | 共通 | 200 |
| 5 | 専用武器のスキル能力強化 | 共通 | 300 |
| 6 | クラス基礎能力強化 | 専用 | 400 |
| 7 | 専用武器の基礎能力強化 | 共通 | 500 |
| 8 | クラス基礎能力強化 | 専用 | 650 |
| 9 | 専用武器の基礎能力強化 | 共通 | 800 |
| 10 | 専用武器の進化が可能になる | 共通 | 1000 |
| 11 | クラス基礎能力強化 | 専用 | 1250 |
| 12 | 専用武器の基礎能力強化 | 共通 | 1500 |

| 20 | 専用武器のスキル能力強化 | 共通 | 10000 |

- 必要経験値は、そのLvに上がるために必要な量(累計ではない)。累計は 42,600
- **メイン武器切り替え(Lv15)**: クラス画面で1番目の武器を、**他クラスのメイン武器**に変更できる。ラン開始時の選択ではない
- **種別**
  - 共通: 武器側の強化。その武器を使うなら、どのクラスでも効く
  - 専用: そのクラスにだけ効く強化
- 武器は、どのクラスが使っても恩恵を受けられる。クラス特性は「通常攻撃」「武器スキル」という形で武器を参照し、特定の武器に依存しない書き方にする
- 各Lvの具体的な強化内容は、クラスの設計ファイルに書く
- ウェポンマスターは専用武器が無いので、全て専用(`classes/weaponmaster.md`)

### 形と費用

- 形: **円形のツリー**
  - 中心から 生命 / 技巧 / 天秤 の3方向に 120° ずつ広がる
  - 深さ = 中心からのリング番号(1〜7。深さ7 は枝の先端)
  - 取得済みのノードに隣接するノードが取得できるようになる
- 費用: `50 × 2^深さ` ゴールド(深さ1 = 100、深さ6 = 3,200)
- **リセットはできない**

- 最奥の特別なノードの効果
  - **食べ物でデバフ解除**: 肉を拾うと、自分の炎上・凍傷・出血・減速・スロウタイム・凍結・疲労・毒・暗闇・痺れ・麻痺・砂塵・衰弱・眩惑が消える(ボスの技の攻撃不能・回復不能は消えない)。消してから回復するので、炎上中でも回復は減らない
  - **アイテム出現率**: 装備宝箱以外のアイテム(コイン・肉・磁石・爆弾)の出る数の倍率。カオス強化「枯れた大地」(-10%/Lv)と掛け合わせ、1 を超えた分はその確率でもう1つ出る(例: +25% なら 25% でもう1つ)
  - **装備初期レベル +n%**: ランの開始時に、装備中の全てのオプションがそれぞれ n% の確率で +1Lv から始まる。100% ごとに確定で +1Lv(100% = 全て +1Lv、150% = 全て +1Lv に加えて 50% でさらに +1Lv)。最大Lv を超えない

### 枝分かれ

各方向は、深さ1 の根ノードから3本の枝に分かれます。

| 方向 | 根(深さ1) | 枝 | 含むノード | 枝の先端(最奥) |
|---|---|---|---|---|
| 生命 | HP ×1 | 活力 | HP ×9、HP回復 ×4 | **食べ物でデバフ解除 ×1**(深さ7) |
| | | 守護 | 防御力 ×4、軽減 ×5 | **食べ物の効果 ×1**(深さ7) |
| | | 持久 | スタミナ ×10、スタミナ回復 ×4 | **アイテム出現率 ×1**(深さ7) |
| 技巧 | 攻撃力 ×1 | 剛撃 | 攻撃力 ×9、クリティカルダメージ ×4 | **装備初期レベル ×1**(深さ7) |
| | | 精妙 | クリティカル率 ×5、クールダウン ×4 | **武器枠 ×1**(深さ7) |
| | | 広域 | 範囲 ×5、射程 ×5、移動速度 ×4 | **装備初期レベル ×1**(深さ7) |
| 天秤 | 吸引範囲 ×1 | 成長 | 経験値 ×4、クラス経験値 ×5(本線に1・行き止まりに4) | **武具強化選択枠 ×1**(深さ7) |
| | | 財宝(真ん中) | ゴールド ×8、装備品質 ×5(本線に2・行き止まりに3)、**リロール ×2**(本線の間。深さ2 = 序盤・深さ4 = 中盤) | **リロール ×1**(深さ7 = 最奥) |
| | | 探索 | 吸引範囲 ×7、宝箱品質 ×5(本線に3・行き止まりに2) | **クラス強化選択枠 ×1**(深さ7) |

- リロール回数と選択枠は奥に置く: リロールは真ん中の財宝に序盤・中盤・最奥の3つ、選択枠は成長(武具強化選択枠)と探索(クラス強化選択枠)の先端。最奥の3つはどれも深さ7(費用 6,400G)
- 9本の枝の全てに、深さ7 の先端(特別なノード)がある
- 枝の中では、同じステータスを連続させず交互に並べる(例: 活力 = HP → HP回復 → HP → ...)
- 深さごとのノード数の例(生命): 深さ1 = 1、深さ2〜5 = 各8、深さ6 = 4、深さ7 = 3
- 1方向を取り切る費用: 生命・技巧 **56,100G**、天秤 **58,900G**(合計 171,100G)
