# 装備

## 5. 装備

### 5.1 部位・種類・レアリティ

| 部位 | 種類 |
|---|---|
| 武器 | 剣 / 杖 / 弓 |
| 防具 | 重鎧 / 軽鎧 / ローブ |
| 指輪 | ルビー / サファイア / エメラルド |

- 装備とクラスのメイン武器は完全に別枠。どのクラスでもすべての装備を装備できる

| レアリティ(tier) | オプション数 | 固有効果 | 強化の上限回数 |
|---|---|---|---|
| コモン | 1 | - | 1 |
| アンコモン | 2 | - | 2 |
| レア | 3 | - | 3 |
| エピック | 4 | - | 4 |
| レジェンダリー | 4 | 部位の候補からランダムに1つ + **二つ名** | 5 |
| ミシック | 4 | レジェンダリーと同じ | 5(全オプションが上限なので強化はできない) |

- **ミシック**(2026-10-13): ガチャだけで出る(宝箱には出ない)。色は赤。レジェンダリーの全オプションが、そのガチャの上限の値(最高ロール値 = 範囲の最大 ×(1 + 装備ロール上限)、最高Lv = 5 + 装備Lv上限)。売却額はレジェンダリーと同じ(強化費用の基礎値 1600 として数える)

### 5.2 オプション

- 基礎効果(固定で付く効果)はない。オプションはすべて種類の候補からランダムに付き、重複はしない
- 生成時に次の2つをロールする
  - **ロール値 v**: 5.3 の範囲からランダム
  - **最大Lv**: 3〜5
- 最大値は `v × 最大Lv`。乗算系(軽減・クールダウン)は `(1 - v)^Lv`
- ラン開始時点では、全オプションが **Lv0**
- レベルアップの**装備カード**で、選んだオプションが +1Lv される(8章。以前の「毎Lv 自動でランダムに1つ」は廃止)

### 5.4 強化(ゴールド)

- 1回の強化で、**ランダムな1オプション**のロール値を **+20〜30%(ランダム)** 伸ばす。上限回数はレアリティで決まる(5.1)
- 費用: 1回目の基礎値は下表。2回目以降は、1回ごとに ×1.5

| コモン | アンコモン | レア | エピック | レジェンダリー |
|---|---|---|---|---|
| 100 | 200 | 400 | 800 | 1600 |

- 売却額: 強化費用の基礎値の 20% + それまでに使った強化費用の 10%
- **表示案**: 「ロール品質」をパーセントで見せる
  - 例: `攻撃力 +8.0% / Lv  [品質 50%] ★★☆`
  - 品質 = (v - 範囲の最小) / (範囲の最大 - 範囲の最小)。強化で 100% を超えた分は金色で表示する

### 5.5 特殊ステータス

装備のオプションには出ないステータスです。

| ステータス | 入手元 |
|---|---|
| 装備最大Lv / 装備最大値% | カオス強化 |
| 装備品質% / 宝箱品質% | ツリー(天秤)・固有効果・カオス強化・tier の報酬の倍率(×1.0〜。`enemies.md` 1.5) |
| 敵出現頻度 / レベル上昇速度% | カオス強化(難易度を上げる側) |
| クラス経験値% | ツリー(天秤)。tier の報酬の倍率は倒したときに掛かる(`enemies.md` 1.5) |
| リロール回数 / クラス強化選択枠 | ツリー(天秤)・固有効果 |
| 武器枠 | ツリー(技巧)・固有効果 |
| 無敵時間 | 固有効果 |
| 食べ物の効果%(肉の回復量。基礎 最大HP の 20%) | ツリー(生命) |
| 食べ物でデバフ解除 / アイテム出現率% | ツリー(生命)。アイテム出現率はカオス強化(枯れた大地)で下がる |
| 装備初期レベル% | ツリー(技巧) |
| 弾数 | 固有効果のみ |

### 5.7 入手・ガチャ・インベントリ

- **ボス撃破**: 装備宝箱をドロップする。1つの宝箱に入る装備の数(枠数)は次の通り

| 枠数 | 基礎確率 |
|---|---|
| 1 | 70% |
| 2 | 25% |
| 3 | 5% |

  - 宝箱品質% で、枠数が多い側に確率が寄る
- **ラン終了時**: 撃破ボス数に応じて宝箱0〜2個。クリアするとさらに +1 個
- 死亡しても、ラン中に得た装備は失われない
- ラン中に入手した装備はインベントリに入る。装備の変更はラン外でのみ行う
- レアリティのドロップ率

| コモン | アンコモン | レア | エピック | レジェンダリー |
|---|---|---|---|---|
| 50% | 30% | 14% | 5% | 1% |

  - 装備品質% でのみ上位に寄せる。後半のボスほど良くなる補正はかけない
- **ガチャ**(2026-10-13 にショップから変えた): ゴールドで装備を引く。1回と 10連(10連の値段は 1回の 10倍。割り引かない)

| ガチャ | 値段(1回) | 作り方 | 装備ロール上限 | 装備Lv上限 |
|---|---|---|---|---|
| 一般 | 150 | カオス強化 0 pt 相当 | +0% | +0 |
| 高級 | 300 | カオス強化 25 pt 相当 | +25% | +1 |
| 最高級 | 500 | カオス強化 50 pt 相当 | +50% | +2 |

  - 「カオス強化 N pt 相当」は、その pt の報酬の 装備ロール上限・装備Lv上限 で作る(装備品質・宝箱品質は使わない。レアリティは下の確率で決まる)
  - レアリティの確率(どのガチャも同じ。装備品質では変わらない)

| コモン | アンコモン | レア | エピック | レジェンダリー | ミシック |
|---|---|---|---|---|---|
| 35% | 30% | 20% | 10% | 4% | 1% |

  - 演出: 玉が落ちる → 溜め(レアリティが高いほど玉の色が 白 → 青 → 紫 → 金 と段を上がる)→ 割れる(光の筋・衝撃の輪・紙吹雪・コイン)→ レアリティの文字 → 装備のカード。ミシックはレジェンダリーの演出のあと、昇格(色あせ・鼓動・赤い稲妻・文字の乱れ・カードのひび)→ 赤い大爆発 → ミシック(カードの値が上限まで上がる)。クリック / SPACE / Enter / ESC で最後まで飛ばす。引いた装備は演出の前にインベントリへ入れて保存する
  - 10連の演出: 玉の色は 10個の中で一番良いレアリティまで上がる → 割れると、カード 10枚が裏向きに飛び出す(裏の色でレアリティを匂わせる。白 / 青 = レア / 紫 = エピック / 金 = レジェンダリー以上)→ 1枚ずつめくる(良いカードの前は少し間をあける)→ 一番良いレアリティの文字。ミシックはレジェンダリーとしてめくり、最後にそのカードが昇格する
  - ボタン(もう1回・OK)は、レアリティの文字が出たときに出す(ユーザーの指定)。ミシックはレジェンダリーの文字のときも出し(先にばれないように)、昇格の間は隠す。昇格の前にボタンを押すと、閉じずに最後まで飛ばす
  - インベントリに入りきらない(10連は 10個)ときは引けない
- **インベントリ**: 上限 1000 個。ロックしていない装備を一括で売却できる
